Ollive is a multi-turn chatbot wrapped in a lightweight SDK that captures inference metadata
(model, provider, latency, token usage, status, previews) and ships it through an event-based
ingestion pipeline into purpose-fit storage, with latency / throughput / error dashboards on top.

These docs follow the [Diátaxis](https://diataxis.fr) framework — find what you need by what you
are trying to do right now:
